# 🏋️ Orca Jym Admin Panel

A sleek, secure, and responsive admin panel for managing gym operations—built with PHP, MySQL, and modern CSS. Features include staff and trainer CRUD, session management, and dynamic data displays.

## 🚀 Features
- Staff and Trainer CRUD operations
- Secure login and session handling
- Responsive UI with modern CSS
- Admin dashboard with dynamic tables
- Form validation and error handling

## 📦 Tech Stack
- PHP (Backend)
- MySQL (Database)
- HTML/CSS/JavaScript (Frontend)
